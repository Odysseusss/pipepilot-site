About Pipe Pilot

Piping software shaped by field work.

Pipe Pilot brings measured isometric drawing, fitting references, pipe data and fabrication information into one browser workspace.

Why it exists

Pipe routing decisions are three-dimensional, but field sketches and fabrication drawings still have to communicate those decisions on a flat page. That translation creates repetitive work: choose a direction, account for fitting takeout, keep dimensions tied to the right datum, and make the result readable to the next person. Pipe Pilot is built to make that work faster without hiding the underlying geometry.

The drawing canvas uses familiar isometric rails and real fitting choices. A run carries its measured length, direction, specification and connections. Fittings remain connected as a route develops, while cut information and reference data stay close to the drawing.

Who it is for

The workspace is intended for pipefitters, steamfitters, plumbers, fabricators, supervisors, estimators and apprentices who need a practical way to capture a piping route. It is not a substitute for engineering approval, code review or an issued design. It is a field and shop tool for communicating measured geometry clearly.

How the product develops

Field reports drive the work. Geometry bugs, awkward direction choices and unclear symbols are treated as product failures to be traced rather than user mistakes. The public changelog records meaningful additions and corrections so visitors can see that the product is actively maintained.

Try the real canvas.The logged-out demo includes measured runs, fittings and dimensions up to a cumulative 25 feet. No guest account is created and the session is not written to the server.
