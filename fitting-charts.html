Why this page does not publish one universal number table

Takeout varies by nominal size, fitting pattern, pressure class, schedule family and manufacturer. Publishing a single unlabeled number is less useful than identifying the governing dimension correctly. Pipe Pilot’s in-app fitting data selectors attach values to the chosen type, size and class so the reference remains contextual.

Calculation reminderRecord whether the field dimension is E–E, E–C or C–C before subtracting takeout. Then apply weld gaps, gasket thickness and any project-specific allowances exactly once.
